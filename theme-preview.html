How to Apply a Theme

Click on any theme card above to preview it. Once you've decided on a theme:

  1. Note the theme name (e.g., "purple", "green", "indigo")
  2. Open each HTML file (index.html, about.html, research.html, etc.)
  3. Find the <html> tag at the top
  4. Change the class from class="theme-blue" to your chosen theme, e.g., class="theme-purple"
  5. Save all files and refresh your browser
