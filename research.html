Adaptive human-machine teaming, and how heterogeneous robots should split a task.

Current

Adaptive human-machine teaming

A machine teammate has to notice when a person is overloaded and change what it does. This project uses objective measures — heart-rate variability, speech rate, noise level — to estimate workload as the task is happening, predict performance in the near term, and then adapt the machine’s interaction or reallocate tasks across the team.

The current algorithms assume the task is known. The next step is to identify the task while it is underway. Sponsors: DARPA/NASA and AFOSR.

Related paper: Design Principles for Building Robust Human-Robot Interaction Machine Learning Models, HRI 2024 companion, with Josh Bhagat Smith, Prakash Baskaran, Mark-Robin Giolando, and Julie A. Adams.

Earlier

Georgia Tech, STAR Lab, with Harish Ravichandar. 2021–2023.

  1. 2023

    Trait preferences

    I developed a method that reads task-specific trait preferences out of expert allocation demonstrations, including how diverse each trait already was in the team, and then allocates robots using those preferences. Sponsored by ARL.

    AAMAS extended abstract

  2. 2023

    Unknown task rewards

    With Sukriti Singh, Anusha Srikanthan, and Harish Ravichandar, I worked on forming coalitions when task rewards are unknown and the team’s resources are limited. The algorithm trades off exploring those rewards against exploiting what it has already learned.

    RSS 2023

  3. 2021–23

    Trainability in decentralized allocation

    I worked on a decentralized multi-robot task allocation method so that feedback about how trainable an agent is, measured at the coalition, could change the allocation.

  4. 2021–23

    StarCraft II demonstrations

    I helped set up a StarCraft II study to collect demonstrations for a Gaussian process used to improve task allocation. Sponsored by ARL.

  5. 2021–23

    Personalized pose detection

    I worked on a personalized embedding for pose prediction, meant to separate differences between people from other kinds of heterogeneity.
